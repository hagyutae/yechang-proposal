# 예비창업패키지(예창패) 사업계획서 작성 가이드

## 프로그램 개요

예비창업패키지는 중소벤처기업부가 창업진흥원을 통해 운영하는 예비창업자 지원 프로그램이다.
- **지원 대상:** 사업자등록 전 예비창업자
- **지원 규모:** 평균 0.5억원 (1단계 20백만원 내외 + 2단계 40백만원 내외)
- **선정 인원:** 총 780명 (일반분야 660명 + 특화분야 120명)
- **협약기간:** 약 8개월
- **선발 방식:** 신청자가 주관기관을 직접 선택 → 주관기관별 서류심사(1차) → 인큐베이팅(2차) → 발표평가(3차)

## 프로젝트 파일 구조

모든 예창패 작업은 워크스페이스에 `bp-project.json` 파일로 저장된다.
파일이 없으면 `/new` 커맨드로 먼저 생성해야 한다.

## 파일 처리 방법 (HWP / PDF)

업로드된 파일을 처리할 때:

### HWP 파일
1. LibreOffice로 docx 변환:
   ```bash
   libreoffice --headless --convert-to docx --outdir /tmp/ "[파일경로]"
   ```
2. python-docx로 텍스트 추출:
   ```bash
   pip install python-docx --break-system-packages -q
   python3 -c "from docx import Document; doc=Document('/tmp/[변환파일].docx'); [print(p.text) for p in doc.paragraphs if p.text.strip()]"
   ```

### PDF 파일
1. pdftotext로 텍스트 추출 (권장):
   ```bash
   pdftotext "[파일경로]" -
   ```
2. pdftotext 없으면 설치:
   ```bash
   pip install pdftotext --break-system-packages -q
   pdftotext "[파일경로]" -
   ```

추출이 실패할 경우 사용자에게 섹션 목록 또는 주관기관 목록을 텍스트로 직접 입력해달라고 요청한다.

## 예창패 심사 기준 (2025년)

### 3단계 평가 프로세스

1. **1단계: 서류평가**
   - 서류 평가를 통해 **1단계 선정규모의 약 2배 내외**가 2단계 진출
   - 평가 항목:
     - 문제인식 (30~40%): 창업 아이템의 개발 배경 및 필요성
     - 실현가능성 (25~35%): 사업기간 내 개발 또는 구체화 계획
     - 성장전략 (15~25%): 차별성, 수익모델, 자금조달 방안, 중장기 성장성
     - 팀(기업)구성 (10~20%): 대표자 및 인력의 기술 역량과 노하우

2. **2단계: 인큐베이팅**
   - 1단계 합격자를 대상으로 약 2개월간의 집중 교육 및 멘토링
   - 사업계획서 고도화, 주관기관별 추가 평가

3. **3단계: 발표평가**
   - 30분 이내 (발표 15~20분 + 질의응답)
   - 2단계를 통과한 자 중 최종 선정 (총 780명)

### 평가 기준 상세

| 평가 항목 | 비중 | 핵심 포인트 |
|----------|------|------------|
| **문제인식** | 30~40% | 구체적 페인포인트, 기존 해결책의 한계, 시장성 검증 |
| **실현가능성** | 25~35% | 마일스톤의 구체성, KPI 명시, 사업비 사용계획, 실행력 |
| **성장전략** | 15~25% | 차별화 포인트, 수익 모델, 자금조달 방안, 중장기 비전 |
| **팀(기업)구성** | 10~20% | 관련 경험, 전문성, 팀 역량, 추진력 |

### 가점 (최대 3점)

- AI대학원 출신: 2점
- 창업경진대회 입상 이력: 1점
- 기후테크 분야: 1점

### 탈락 기준

- **60점 미만:** 탈락
- 평가 항목별로 부족한 부분이 누적되면 탈락 가능성 높음

**예창패 평가에서 특히 중요한 것:**
- "왜 지금 이 문제를 해결해야 하는가" — 문제의 시급성과 규모, 시장 검증
- "왜 내가 이것을 할 수 있는가" — 창업자 스토리와 전문성의 연결
- "어떻게 돈을 버는가" — 구체적이고 현실적인 수익 모델
- "얼마나 빠르게 성장할 수 있는가" — 초기 고객 확보 전략과 스케일업 경로

## 주관기관 선정 전략

### 주관기관이란
창업진흥원이 예창패 운영을 위탁한 기관들이다. 대학교, 창업지원기관, 액셀러레이터, 연구기관 등이 포함된다.
2025년 기준 총 26개 기관 (일반분야 24개 + 여성/소셜벤처 특화 2개)
신청자는 전국 주관기관 중 하나를 선택해 지원하며, 해당 기관의 심사를 거친다.

### 주관기관 선정 시 고려 요소
1. **특화분야 일치도** (가장 중요) — 내 아이템이 기관의 특화분야와 맞아야 심사위원 풀도 맞고 가점 가능성도 높다
2. **신청 분야 부합도** — 일반분야인지 여성특화인지 소셜벤처특화인지 확인
3. **경쟁률** — 기관별로 지원자 수가 크게 다름. 경쟁률이 낮은 기관이 전략적으로 유리할 수 있음
4. **지역** — 멘토링이 오프라인으로 진행될 수 있으므로 접근 가능한 지역 고려
5. **선발 인원** — 기관별 배정 인원 수 확인
6. **추가 혜택** — 기관 자체 보육 공간, 네트워크, 후속 지원 프로그램

### 주관기관 소개 자료 분석 방법
소개 자료에서 다음을 추출한다:
- 기관명 / 운영 기관 유형
- 특화분야 키워드
- 신청 분야별 선발 예정 인원
- 지역 / 소재지
- 지원 내용 (보육공간, 추가 지원금, 멘토링 등)

추출 후 신청자 아이템의 분야, 기술 키워드, 위치를 종합해 상위 3~5개 기관을 추천하고 선택 이유를 명시한다.

## 예창패 사업계획서 작성 원칙

### 2025년 섹션 구조

```
1. 일반현황
   - 창업아이템명
   - 산출물 (지원금으로 만들 결과물)
   - 팀구성현황

2. 창업아이템 개요(요약)
   - 명칭, 범주, 개요
   - 문제인식, 실현가능성, 성장전략, 팀구성
   - 이미지

3. 1.문제인식(Problem) — 창업 아이템의 필요성

4. 2.실현가능성(Solution) — 창업 아이템의 개발 계획
   - 사업추진일정
   - 1단계 정부지원사업비 집행계획
   - 2단계 정부지원사업비 집행계획

5. 3.성장전략(Scale-up) — 사업화 추진 전략
   - 중장기 사회적 가치 및 ESG

6. 4.팀구성(Team) — 대표자 및 팀원 구성 계획
   - 협력기관

**전체 제약: 15페이지 이내 (목차 제외)**
```

### IT/AI 분야 특화 가이드

**문제 정의 섹션:**
- "AI를 활용한 X" 식의 기술 중심 서술은 지양
- "Y라는 문제로 인해 Z의 비용/시간/리스크가 발생한다"는 구조로 시작
- 잠재 고객의 실제 경험을 근거로 삼는다 (인터뷰, 설문, 직접 경험)

**솔루션 섹션:**
- 핵심 기능 3~5가지 이내로 집중
- 기술보다 "사용자가 얻는 결과"를 먼저 서술
- 데모, 프로토타입, MVP가 있으면 반드시 언급

**시장 분석:**
- TAM→SAM→SOM 구조 필수
- IT/AI 분야는 국내외 시장 모두 언급하는 것이 유리
- 공신력 있는 출처 (IITP, IDC, Gartner, 정부 보고서 등) 인용

**수익 모델:**
- SaaS, B2B 구독, API 과금 등 IT 비즈니스 모델을 명확히
- 초기 수익화 타임라인과 첫 번째 유료 고객 확보 계획 포함

**창업자 역량:**
- 해당 문제를 왜 내가 푸는지 — 경험, 전문성, 도메인 지식
- 팀 구성이 있으면 역할 분담과 각자의 강점 명시
- 관련 수상, 활동, 프로젝트 이력 적극 활용

## 외부 자료 리서치 (`/research`)

사업계획서에 외부 데이터(시장 규모, 경쟁사, 기술 동향 등)를 반영할 때 `/research` 커맨드를 사용한다.

### 활용 시나리오
- **문제 인식 보강**: 시장 규모 통계, 기존 솔루션의 한계 기사, 고객 페인포인트 설문 결과
- **실현 가능성 보강**: 기술 트렌드 보고서, 유사 서비스 사례, 특허/논문 데이터
- **성장전략 보강**: TAM/SAM/SOM 산출 근거, 경쟁사 분석, 정부 정책 방향
- **팀 구성 보강**: 업계 전문가 요건, 관련 수상/활동 뒷받침 자료

### 리서치 자료 관리
- 수집된 자료는 `research-notes.md`에 누적 저장된다
- 각 자료에는 출처(URL, 매체명, 발행일)가 기록된다
- `/write` 실행 시 research-notes.md가 있으면 관련 데이터를 자동으로 참고한다

### 출처 표기 원칙
- 공신력 있는 출처 우선: 정부/공공기관 > 전문 리서치기관 > 언론 > 블로그
- 사업계획서 내 인용 시: "(출처: {매체명}, {연도})" 형태로 표기
- 2년 이상 된 데이터는 최신 자료로 교체 권장

자세한 섹션별 템플릿은 `references/section-templates.md`,
주관기관 선정 체크리스트와 예창패 합격 사례 분석은 `references/yechang-guide.md`를 참조한다.
