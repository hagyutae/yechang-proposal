   - 법률·사업비 관리: 동국대(우수기업 투자, 환수금 0원)
   - 바이오/의료: 서울대 시흥, 연세대

3. **지원 인프라**:
   - 입주공간 필요 여부
   - 메이커스페이스 이용 필요 여부
   - 투자 연계 중요도
   - 특화 교육 프로그램

4. **지원 프로그램**:
   - 개별 기관 프로그램 비교
   - 창업 단계별 필요 프로그램 확인
