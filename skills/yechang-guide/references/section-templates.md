# 예비창업패키지 2025년 섹션 템플릿

## 2025년 표준 섹션 구성

예창패 2025년 공고 기준 사업계획서는 다음과 같이 구성된다.
**총 15페이지 이내 (목차 제외) 제약이 있다.**
이 템플릿은 각 섹션 작성 시 참고용 가이드로 사용한다.

---

## 1. 일반현황

**목적:** 아이템의 기본 정보와 산출물, 팀 구성을 명확히 한다.

### 1-1. 창업아이템명

**작성법:**
아이템명은 기업명·브랜드명·플랫폼명이 아니다. 아래 3요소를 조합해 한 줄만 읽어도 사업 내용을 상상할 수 있게 작성한다.

```
아이템명 = 타겟 + 기술 + 기능(형태)
(순서는 바꿔도 무방. 전국민 대상이면 타겟 생략 가능)
```

**좋은 예:**
- "AI 어시스턴트 기술이 적용된 시니어 디지털 맞춤형 사용지원 서비스"
- "중소 제조업체를 위한 엣지 AI 비전 기반 실시간 불량 탐지 검사 솔루션"

**나쁜 예 (감점 대상):**
- "AI 시니어 프렌드" → 기술과 기능이 보이지 않음
- "스마트 라이프 케어 플랫폼" → 추상적 단어 나열, 실제 무엇을 하는지 불명확

### 1-2. 산출물 (중요)

> ⚠️ **이 섹션은 선정 후 수정 불가. 미완성 시 사업비 전액이 환수될 수 있습니다.**

**목적:** 지원금(약 5천만원)으로 9개월 내 완성할 구체적인 결과물을 명확히 제시한다.

**핵심 원칙:**
- "앱 1개, 홈페이지 1개"처럼 형태만 쓰는 것은 불충분
- 어떤 **기능이 내장된** 앱/서비스인지 구체적으로 기술해야 한다
- 9개월 후 최종 평가 시 실제로 만들었는지 확인하므로, 현실적으로 만들 수 있는 것만 작성
- 과장하지 말 것

**좋은 예:**
> "AI 기반 실시간 불량 탐지 기능, 불량 이미지 데이터 자동 라벨링 기능, 관리자 대시보드(불량률 통계, 알람 설정)가 포함된 웹 기반 품질 관리 SaaS 플랫폼 1식"

**나쁜 예:**
> "AI 품질 관리 앱 1개" → 어떤 기능인지 전혀 불명확, 심사 감점

**작성 체크리스트:**
- [ ] 산출물의 형태(앱/플랫폼/디바이스/시스템 등)가 명확한가
- [ ] 핵심 기능이 구체적으로 나열되어 있는가 (3~5개 권장)
- [ ] 지원금 범위(약 5천만원) 내에서 실제 제작 가능한가
- [ ] 9개월 이내에 완성 가능한 범위인가
- [ ] 과장되거나 실현 불가능한 항목이 없는가

### 1-3. 팀구성현황

팀원 이름, 역할, 주요 경력을 표로 정리한다. 자세한 내용은 섹션 4(팀구성)에서 다룬다.

## 2. 창업아이템 개요(요약)

**목적:** 심사위원이 가장 먼저 보는 요약. 어떤 서비스인지, 얼마나 필요한지, 무엇이 다른지를 한눈에 전달한다.

**포함 내용:**
- 명칭, 범주, 개요
- 문제인식, 실현가능성, 성장전략, 팀구성 요약
- 이미지·인포그래픽 (권장)

**핵심 원칙:**
- 텍스트보다 **이미지·인포그래픽 중심**으로 구성한다 (수백 줄 설명보다 훨씬 효과적)
- 분량은 2페이지 이내로 간결하게
- 처음부터 요약을 쓰려 하면 막히므로, 세부 파트를 완성한 뒤 각 파트의 핵심을 추출해 채운다

**작성 순서:**
1. 나머지 모든 섹션 작성 완료
2. 각 섹션에서 가장 핵심적인 1~2문장/수치를 추출
3. 요약 페이지에 이미지·도표와 함께 배치

## 3. 1.문제인식(Problem) — 창업 아이템의 필요성

**목적:** 이 문제가 실재하며 시급하다는 것을 증명한다.

**포함 내용:**
- 문제의 구체적 상황과 발생 원인
- 문제로 인한 피해/불편 (수치 포함)
- 기존 해결책의 한계
- 창업자가 이 문제를 인식하게 된 계기

**작성 구조:**
```
1. 현상: [구체적인 상황 묘사]
2. 원인: [왜 이 문제가 발생하는가]
3. 피해: [고객이 겪는 손실 — 비용/시간/리스크를 수치로]
4. 현재 해결책: [기존 방식이 있지만 한계가 있음]
5. 창업 계기: [창업자가 직접 겪었거나 발견한 스토리]
```

**팩트 + 인사이트 연결:**

팩트(통계·데이터)만 나열하면 공감을 얻기 어렵다. 팩트 다음에 반드시 **인사이트(의미 해석)**를 연결해야 한다.

```
[팩트] 환경 변화나 통계 수치 제시
  → [인사이트] 이 변화가 왜 문제를 악화/해소 가능하게 만드는가
  → [결론] 따라서 우리 솔루션이 지금 필요하다
```

**고객 검증 (중요):**
- FGI(Focus Group Interview): 5~10명의 목표 고객 심층 인터뷰
- 설문조사: 정량적 데이터 확보
- 인터뷰 현장 사진, 설문 결과 캡처를 이미지로 삽입 (권장)

**고객 테스트를 4단계 스토리로 엮기:**
```
① 초기 아이디어 단계  → 고객 반응 확인 (가정 검증)
② 아이디어 필터링    → 가장 큰 페인포인트 선별
③ 시제품/프로토타입  → 실제 사용성 피드백 수집 및 개선
④ 최종 고도화       → 개선 내용 반영 결과
```

## 4. 2.실현가능성(Solution) — 창업 아이템의 개발 계획

**목적:** 문제를 어떻게 해결하는지, 구체적인 실행 계획을 명확하게 설명한다.

### 4-1. 솔루션 개요

**포함 내용:**
- 제품/서비스의 핵심 기능 (3~5가지 이내로 집중)
- 작동 방식 (기술적 설명, 비전공자도 이해 가능하게)
- 기존 대안 대비 차별화 포인트
- 현재 개발 상태 (아이디어/프로토타입/MVP/파일럿 중)

**IT/AI 특화 팁:**
- 기술 스택 나열 대신 "이 기술로 무엇이 가능해지는가"를 설명
- 스크린샷, UI 목업, 플로우차트가 있으면 첨부 (가능한 경우)
- AI 모델이라면 학습 데이터와 정확도 지표 언급

### 4-2. 시장 분석 (TAM → SAM → SOM)

```
[TAM] 글로벌/국내 전체 시장: X조원 (출처, 연도)
[SAM] 실제 접근 가능 시장: Y억원 (세그먼트 필터 기준)
[SOM] 3년 내 목표 시장점유율: Z억원 (초기 전략 기반)
```

**SOM 직접 산출법 (Bottom-up 방식):**

공신력 있는 TAM/SAM 수치를 인용하되, SOM은 아래 공식으로 직접 계산:

```
SOM 시장 규모 = 목표 고객 인원수 × 구매/이용 빈도 × 단가
```

**예시:**
> "국내 중소 제조업체 약 12만 개(통계청 기준) 중 품질 검사 자동화 미도입 업체 30%(3.6만 개) × 연 1회 도입 × 300만원 = 약 1,080억원 규모의 SOM"

**경쟁 분석 (필수):**

"경쟁사가 없습니다"는 절대 금지. 직접 경쟁사가 없더라도 고객이 현재 사용하는 대체 수단(엑셀, 수작업, 기존 장비 등)을 간접 경쟁사로 분석.

| 구분 | 자사 | 경쟁사 A | 경쟁사 B |
|------|------|---------|---------|
| 핵심 기능 | ✅ | ✅ | ❌ |
| 가격 | 저가 | 고가 | 중가 |
| 도입 용이성 | 쉬움 | 복잡 | 보통 |

### 4-3. 사업추진일정

마일스톤을 월별 또는 분기별로 제시한다. **각 마일스톤마다 측정 가능한 KPI를 명시해야 한다.**

| 시기 | 목표 | KPI | 담당 |
|------|------|-----|------|
| 1~3개월 | 핵심 기능 개발 | 기능 3개 구현, 내부 테스트 통과 | 외주 개발팀 + 대표 |
| 4~6개월 | 파일럿 고객 확보 | 파일럿 3개사, NPS 60점 이상 | 대표 직접 영업 |
| 7~10개월 | 유료 전환 | 유료 전환 1건 이상, 매출 OOO만원 | 전체 팀 |

**KPI 작성 원칙:**
- ❌ "프로토타입 완성" → ✅ "핵심 기능 3가지 구현, 내부 테스트 통과"
- ❌ "고객 확보" → ✅ "파일럿 계약 3건, 무료→유료 전환율 33% 이상"

### 4-4. 1단계 정부지원사업비 집행계획

1단계 지원금(약 20백만원)의 비목별 사용 계획을 제시한다.

**비목 항목:**
- 재료비, 외주용역비, 기계장치, 특허권등무형자산취득비
- 인건비, 지급수수료, 여비, 교육훈련비
- 광고선전비, 창업활동비(월 50만원 한도)

| 비목 | 금액(백만원) | 사용 목적 |
|------|----------|---------|
| 외주용역비 | 8 | 핵심 기능 개발 외주 |
| 기계장치 | 3 | 테스트 환경 구축 |

### 4-5. 2단계 정부지원사업비 집행계획

2단계 지원금(약 40백만원)의 비목별 사용 계획. 보통 파일럿, 마케팅, 인건비 등이 포함된다.

## 5. 3.성장전략(Scale-up) — 사업화 추진 전략

**목적:** 사업화 전략과 중장기 비전, 사회적 가치를 제시한다.

### 5-1. 수익 모델

**IT/AI 수익 모델 예시:**
- SaaS 월정액: "기업당 월 50만원, 최소 계약 6개월"
- API 과금: "API 호출 1만 건당 1만원"
- B2B 솔루션: "기본 도입비 500만원 + 연간 유지보수 20%"

### 5-2. 중장기 비전 및 성장 경로

- 단기(1년): [구체적 목표]
- 중기(3년): [성장 전략]
- 장기(5년): [최종 비전]

고용 창출 계획, 후속 투자/정부지원 계획, 글로벌 진출 전략 포함.

### 5-3. 중장기 사회적 가치 및 ESG

**환경(E):**
- 폐기물감소, 재활용, 친환경원료, 에너지절감

**사회(S):**
- 지역사회 기여, 인권·다양성, 산업 발전 기여, 고용 창출

**지배구조(G):**
- 윤리경영, 근로환경 개선, 투명한 의사결정

예: "우리는 제조업 자동화를 통해 불량률을 50% 감소시켜 폐기물을 감소하고 (환경), 중소기업의 생산성 향상으로 고용 안정화를 도모하며 (사회), 투명한 가격 정책과 고객 피드백 중심 개발로 신뢰 기반 사업을 진행합니다 (지배구조)."

## 6. 4.팀구성(Team) — 대표자 및 팀원 구성 계획

**목적:** "왜 우리가 이 문제를 해결할 적임자인가"를 보여준다.

**포함 내용:**
- 대표자 이력 (아이템과 연결된 경력 중심, 학력보다 실무 경험 우선)
- 팀원 구성과 역할 (어벤져스 포지션 관점)
- 보유 기술, 특허, 논문, 수상 이력 (구체적 제목·기관명 명시)
- 협력기관, 멘토 또는 자문단 (있는 경우, 분야와 역할 명시)

### 6-1. 어벤져스 팀 전략

팀 구성은 해당 아이템을 성공시키기 위해 **반드시 필요한 포지션**을 먼저 정의하고, 현실에서 채워 나가는 방식으로 접근한다.

**포지션 정의 방법:**
1. 아이템 실현에 필요한 핵심 역량 영역을 나열 (기술/도메인/사업/마케팅 등)
2. 각 영역에 최적의 이력을 가진 사람을 매핑
3. 비어 있는 포지션은 현재 팀원 모집 중임을 명시해도 무방

**예시:**
- IT/AI B2B SaaS: AI 엔지니어 + 도메인 전문가(고객 업종) + 영업/BD + UX 디자이너

**작성 팁:**
- "팀원이 있다"를 나열하는 게 아니라 "왜 이 조합인가"의 논리를 보여준다
- 혼자 시작하는 경우: 모집 중인 포지션과 그 이유를 제시하면 오히려 전략적으로 보임
- 수상/논문/특허는 구체적 제목과 기관명 명시

## 최종 체크리스트

**15페이지 이내 제약 유의:**
- 각 섹션의 분량을 적절히 조정해 전체 15페이지를 초과하지 않도록 주의
- 이미지/도표로 텍스트 량 감소
- 핵심만 집중

**전체 검토:**
- [ ] 아이템명이 설명형 (타겟+기술+기능)인가
- [ ] 산출물이 구체적이고 현실적인가
- [ ] 문제가 수치로 검증되었는가
- [ ] 마일스톤과 KPI가 명확한가
- [ ] 팀이 어벤져스 구성인가
- [ ] ESG/사회적 가치가 포함되었는가
- [ ] 이미지/도표가 각 섹션에 최소 1개씩 있는가
