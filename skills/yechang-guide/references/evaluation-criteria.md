# 예비창업패키지(예창패) 2025년 심사 기준 및 체크리스트

## 예창패 공식 심사 항목 및 비중

창업진흥원 예비창업패키지의 서류 및 발표 심사는 아래 4개 항목으로 구성된다 (2025년 공고 기준).

| 심사 항목 | 비중 | 세부 평가 내용 |
|----------|------|--------------|
| **문제인식** | 30~40% | 창업 아이템의 개발 배경 및 필요성, 시장성 검증 |
| **실현가능성** | 25~35% | 창업 아이템의 사업기간 내 개발 또는 구체화 계획, 실행 가능성 |
| **성장전략** | 15~25% | 창업 아이템의 사업화를 위한 차별성, 수익모델, 자금조달 방안 |
| **팀(기업)구성** | 10~20% | 대표자 및 고용(예정)인력이 보유한 기술 역량과 노하우 |

**가점 정보 (최대 3점):**
- AI대학원 출신: 2점
- 창업경진대회 입상 이력: 1점
- 기후테크 분야: 1점

**탈락 기준:**
- 60점 미만: 탈락

---

## 항목별 심사 체크리스트

### 1. 문제인식

- [ ] **아이템명이 타겟+기술+기능(형태) 3요소를 포함하는가** (브랜드명·플랫폼명이 아닌 설명형)
- [ ] 아이템명만 읽어도 어떤 사업인지 상상할 수 있는가 (추상적 단어 나열 금지)
- [ ] 해결하려는 문제가 구체적인 타겟 고객의 실제 상황으로 서술되어 있는가
- [ ] 문제로 인한 피해나 불편이 수치로 표현되어 있는가 (비용, 시간, 리스크 등)
- [ ] 고객 인터뷰, 설문, 직접 경험 등 문제 검증 근거가 있는가
- [ ] 기존 해결책(경쟁제품/서비스)의 한계가 명확히 제시되어 있는가
- [ ] 솔루션이 기존 대안 대비 명확한 차별화 포인트를 갖고 있는가
- [ ] 차별화가 수치 또는 구체적 사례로 뒷받침되는가
- [ ] "AI를 활용한" 식의 기술 중심 서술이 아닌 고객 가치 중심으로 표현되어 있는가
- [ ] 팩트(데이터)와 인사이트(의미 해석)가 연결되어 있는가

---

### 2. 실현가능성

- [ ] 목표 시장이 TAM → SAM → SOM 구조로 제시되어 있는가
- [ ] 시장 규모 수치에 공신력 있는 출처(IITP, IDC, 정부 보고서 등)가 인용되어 있는가
- [ ] SOM(단기 목표 시장)이 현실적인 수준인가
- [ ] 수익화 방식(가격, 과금 방식)이 구체적으로 제시되어 있는가
- [ ] 첫 번째 유료 고객 확보 계획이 있는가 (파일럿, LOI, 파이프라인 등)
- [ ] 사업화 마일스톤이 지원금 사용 기간(약 8개월) 내에 실현 가능한가
- [ ] **마일스톤 각 단계마다 측정 가능한 KPI가 명시되어 있는가** (단순 "완성" 목표 나열 금지)
- [ ] 개발인력 또는 외주 파트너 계획이 실행 계획에 언급되어 있는가
- [ ] 자금 사용 계획이 사업화 활동(파일럿, 마케팅, 시제품 등) 중심으로 구성되어 있는가
- [ ] 인건비 비중이 과도하게 높지 않은가 (30% 이하 권장)

**2025년 자금 가이드:**
- 1단계: 20백만원 내외
- 2단계: 40백만원 내외
- 비목: 재료비, 외주용역비, 기계장치, 특허권등무형자산취득비, 인건비, 지급수수료, 여비, 교육훈련비, 광고선전비, 창업활동비(월50만원한도)

---

### 3. 성장전략

- [ ] 사업화 전략이 단기(1년)와 중장기(3~5년) 관점에서 제시되어 있는가
- [ ] 차별화 포인트가 명확하고 지속 가능한가
- [ ] 수익 구조가 단계적으로 확장될 수 있는가
- [ ] 고용 창출 계획이 언급되어 있는가
- [ ] 중장기 사회적 가치와 ESG가 고려되어 있는가

**ESG 가이드:**
- **환경(E):** 폐기물감소, 재활용, 친환경원료, 에너지절감
- **사회(S):** 지역사회 기여, 인권·다양성, 산업 발전 기여
- **지배구조(G):** 윤리경영, 근로환경 개선, 투명한 의사결정

- [ ] 후속 정부지원(중기창업패키지 등) 또는 투자 유치 계획이 있는가
- [ ] 글로벌 또는 대규모 확장 가능성이 현실적 근거와 함께 서술되어 있는가

---

### 4. 팀(기업)구성

- [ ] 창업자의 경력·경험이 해결하려는 문제와 직접 연결되는가 ("왜 내가" 스토리)
- [ ] 관련 분야 전문성이 학력이 아닌 실제 경험 중심으로 서술되어 있는가
- [ ] 수상, 프로젝트, 논문, 특허 등 관련 이력이 구체적으로 기재되어 있는가
- [ ] **어벤져스 팀 관점: 아이템 실현에 필요한 핵심 포지션이 모두 채워져 있는가**
- [ ] 팀원 각각이 "왜 이 아이템에 최적인가"가 역할·경력으로 설명되는가
- [ ] 비어 있는 포지션이 있다면 모집 계획이 명시되어 있는가
- [ ] 창업에 대한 full-time 전념 여부가 드러나는가
- [ ] 협력기관이나 자문단이 있으면 역할과 관련성이 명시되어 있는가

---

## 섹션 구조별 평가 가이드

### 일반현황 & 창업아이템 개요(요약)

체크리스트:
- [ ] 한 문장으로 아이템을 이해할 수 있는가
- [ ] 고객-문제-솔루션의 흐름이 명확한가
- [ ] 산출물이 구체적인가 (형태 + 포함될 기능 목록)
- [ ] 산출물이 9개월 내 현실적으로 완성 가능한가
- [ ] 이미지/도식이 포함되어 있는가
- [ ] 팀 구성이 명시되어 있는가

### 문제인식(Problem)

체크리스트:
- [ ] 구체적 타겟 고객이 명시되어 있는가
- [ ] 문제로 인한 피해가 수치화되어 있는가
- [ ] 기존 해결책의 한계가 명확한가
- [ ] 고객 검증 근거(인터뷰/설문)가 있는가
- [ ] 팩트와 인사이트가 연결되어 있는가

### 실현가능성(Solution)

체크리스트:
- [ ] 핵심 기능 3~5가지가 명확한가
- [ ] 마일스톤과 KPI가 구체적인가
- [ ] 자금 사용 계획이 비목 중심으로 구성되어 있는가
- [ ] TAM→SAM→SOM 단계가 있는가
- [ ] 초기 고객 확보 계획이 있는가

### 성장전략(Scale-up)

체크리스트:
- [ ] 단기/중기/장기 비전이 제시되어 있는가
- [ ] 수익 모델 확장 경로가 있는가
- [ ] ESG/사회적 가치가 포함되어 있는가
- [ ] 고용 창출 계획이 있는가

### 팀구성(Team)

체크리스트:
- [ ] 각 팀원의 관련 경력이 명시되어 있는가
- [ ] "왜 이 팀인가"의 설득력이 있는가
- [ ] 비어 있는 포지션에 대한 모집 계획이 있는가

---

## PSST 전체 일관성 체크

계획서 전체가 **Problem → Solution → Scale → Team** 논리 흐름으로 일관되어야 한다.

- [ ] **P (Problem):** 문제가 구체적이고 수치로 검증되어 있는가
- [ ] **S (Solution):** 솔루션이 해당 문제를 직접 해결하는가 (엉뚱한 해결책 금지)
- [ ] **S (Scale):** 시장이 충분히 크고 성장 중인가 (SOM이 현실적인가)
- [ ] **T (Team):** 팀이 이 문제를 해결하기에 가장 적합한 이유가 드러나는가
- [ ] 네 요소가 서로 모순 없이 하나의 스토리로 연결되는가

---

## 최종 체크리스트

제출 전 반드시 확인:

- [ ] 아이템명이 설명형 (타겟+기술+기능)인가
- [ ] 15페이지 이내 (목차 제외)를 준수했는가
- [ ] 개인정보(주민등록번호, 계좌번호 등) 마스킹이 되어있는가
- [ ] 이미지/도표가 각 섹션에 최소 1개씩 포함되어 있는가
- [ ] "AI를 활용한" 식의 기술 중심 서술이 없는가
- [ ] 경쟁사가 "없다"고 표현하지 않았는가
- [ ] 마일스톤에 KPI가 명시되어 있는가
- [ ] 고객 검증 근거(FGI/설문)가 포함되어 있는가
- [ ] 선택한 주관기관의 특화분야와 아이템 연관성이 드러나는가
