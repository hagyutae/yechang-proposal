예비창업패키지(예창패) 사업계획서 프로젝트를 새로 시작한다.
플러그인에 2025년 예창패 자료가 내장되어 있으므로 별도 파일 업로드 없이 바로 시작할 수 있다.
더 최신 연도 자료가 있으면 업로드하면 그 자료 기준으로 진행한다.

---

## Step 1: 기본 정보 수집

사용자에게 다음을 한 번에 질문한다:
1. 아이디어/사업명 (없으면 나중에 정해도 됨)
2. 신청자명
3. 팀명 또는 예정 법인명 (없으면 생략)
4. 신청 연도 (기본값: 2025)
5. 신청 분야 선택: 일반분야 / 특화분야(여성) / 특화분야(소셜벤처)
6. 아이템의 분야/키워드 (예: AI, 헬스케어, B2B SaaS 등) — 주관기관 추천에 사용

---

## Step 2: 자료 확인 및 업로드 옵션

사용자에게 다음을 안내한다:

```
플러그인에 2025년 예창패 자료가 내장되어 있습니다. 별도 파일 업로드 없이 바로 시작할 수 있습니다.

더 최신 연도 자료가 있다면 아래 파일들을 순서대로 업로드해주시면 해당 자료 기준으로 진행합니다:

📄 [선택] 예비창업패키지 사업계획서 양식 (HWP/PDF)
📋 [선택] 예비창업패키지 주관기관 소개 자료 (HWP/PDF)
📰 [선택] 예비창업패키지 2025년 모집공고 (HWP/PDF)
❓ [선택] 모집공고 주요 질의응답(Q&A) (HWP/PDF)
```

**파일을 업로드하지 않으면:** 내장된 2025년 자료로 자동 진행
**파일을 업로드하면:** 해당 파일을 파싱 후 기존 2025년 자료 대신 사용

업로드 파일이 있는 경우만 Step 3으로 진행, 없으면 Step 4로 건너뛴다.

---

## Step 3: 파일 파싱 (업로드된 경우만)

업로드된 각 파일에 대해 아래 방법으로 텍스트를 추출한다.

### 파일 형식 판별

```bash
ls -la [업로드 폴더] 2>/dev/null | tail -20
```

업로드된 파일명을 확인하고 확장자(`.hwp`, `.hwpx`, `.pdf`)로 형식을 판별한다.

### HWP/HWPX 파일 처리

```bash
libreoffice --headless --convert-to docx --outdir /tmp/ "[파일경로]" 2>&1
```

변환 성공 시:
```bash
pip install python-docx --break-system-packages -q 2>/dev/null
python3 << 'EOF'
from docx import Document
doc = Document('/tmp/[변환된파일명].docx')
for para in doc.paragraphs:
    if para.text.strip():
        print(f"[{para.style.name}] {para.text}")
EOF
```

### PDF 파일 처리

```bash
pdftotext "[파일경로]" - 2>/dev/null
```

pdftotext 없으면:
```bash
pip install pdftotext --break-system-packages -q 2>/dev/null
pdftotext "[파일경로]" -
```

모든 방법이 실패하면 사용자에게 섹션 목록/주관기관 목록을 직접 텍스트로 입력해달라고 요청한다.

---

## Step 4: 섹션 구조 추출 (내장 2025 자료 또는 업로드 파일 기반)

사업계획서 양식에서 **작성해야 할 섹션 목록**을 식별한다.
내장 자료인 경우 `skills/yechang-guide/references/2025-data/` 의 양식 정보를 사용한다.

2025년 표준 섹션 구조:
```
1. 일반현황
   - 창업아이템명
   - 산출물 (지원금으로 만들 결과물)
   - 팀구성현황

2. 창업아이템 개요(요약)
   - 명칭
   - 범주
   - 개요
   - 문제인식
   - 실현가능성
   - 성장전략
   - 팀구성
   - 이미지

3. 1.문제인식(Problem) — 창업 아이템의 필요성

4. 2.실현가능성(Solution) — 창업 아이템의 개발 계획
   - 사업추진일정
   - 1단계 정부지원사업비 집행계획
   - 2단계 정부지원사업비 집행계획

5. 3.성장전략(Scale-up) — 사업화 추진 전략
   - 중장기 사회적 가치 ESG 포함

6. 4.팀구성(Team) — 대표자 및 팀원 구성 계획
   - 협력기관 포함
```

섹션 목록을 번호, 제목, 글자 수 제한(있는 경우)과 함께 표로 정리해서 보여준다.

---

## Step 5: 주관기관 추천

내장 2025년 주관기관 데이터(`skills/yechang-guide/references/2025-data/host-institutions.md`)를 분석하여,
Step 1에서 입력받은 **아이템 분야/키워드**와 비교한다.

추천 기준:
- 특화분야 키워드 일치도 (40%)
- 신청 분야별 기관 (일반분야/여성특화/소셜벤처특화) (30%)
- 지역 접근성 (15%)
- 추가 지원 혜택 (10%)
- 선발 인원 규모 (5%)

**상위 3개 주관기관**을 다음 형식으로 추천한다:

```
## 🏢 추천 주관기관

### 1순위: [기관명] ⭐
- **특화분야:** [분야]
- **신청 분야:** [일반/여성/소셜벤처]
- **추천 이유:** [아이템과의 연관성, 구체적 이유]
- **선발 인원:** [명] | **지역:** [지역]
- **추가 혜택:** [있는 경우]

### 2순위: [기관명]
...

### 3순위: [기관명]
...

> 최종 선택은 사용자가 결정하며, `/new` 이후 주관기관을 변경하려면 알려주세요.
```

사용자에게 주관기관을 선택해달라고 요청한다.

## Step 6: 프로젝트 파일 생성

워크스페이스에 `bp-project.json` 파일을 생성한다.
기존 파일이 있으면 덮어쓸지 확인한다.

수집된 모든 정보(기본 정보, 선택된 주관기관, 섹션 목록, 업로드 파일 여부)를 JSON에 저장한다.

```json
{
  "program": "예비창업패키지",
  "year": "2025",
  "title": "아이디어/사업명",
  "company_name": "팀명 또는 예정 법인명",
  "applicant_name": "신청자명",
  "application_category": "일반분야|여성특화|소셜벤처특화",
  "selected_host": {
    "name": "선택된 주관기관명",
    "specialty": "특화분야",
    "region": "지역",
    "reason": "선택 이유"
  },
  "data_source": "built-in-2025",
  "template_source": "기본값 또는 업로드파일명",
  "sections": [
    {
      "id": "1",
      "title": "섹션 제목",
      "content": "",
      "status": "empty",
      "char_limit": 0,
      "notes": "작성 시 유의사항"
    }
  ],
  "metadata": {
    "field": "아이템 분야/키워드",
    "host_candidates": []
  },
  "created_at": "ISO 날짜",
  "updated_at": "ISO 날짜"
}
```

## Step 7: 완료 안내

다음 내용을 출력한다:
- 생성된 섹션 목록 (번호 + 제목 + 상태)
- 선택된 주관기관
- 사용된 자료 출처 (내장 2025년 또는 업로드 파일)
- 다음 단계 안내:
  - `/write [섹션번호]` — 섹션 작성 또는 수정
  - `/review` — 검토 및 피드백
  - `/export word` 또는 `/export pdf` — 최종 출력
  - `/update [연도]` — 새로운 연도 자료로 업데이트
