---
description: 새로운 연도 예창패 자료로 기존 프로젝트 업데이트
allowed-tools: Read, Write, Bash
argument-hint: [연도 (예: 2026)]
---

기존 예창패 프로젝트에 새로운 연도의 예창패 자료를 적용하거나 업데이트한다.

---

## Step 1: 프로젝트 파일 확인

워크스페이스에서 `bp-project.json`을 읽는다.
파일이 없으면: "먼저 `/new` 명령으로 예창패 프로젝트를 시작해 주세요."라고 안내하고 중단한다.

현재 프로젝트의 기본 정보(신청자, 팀명, 아이템명 등)를 확인한다.

---

## Step 2: 새로운 자료 업로드 요청

사용자에게 새로운 연도($ARGUMENTS 또는 사용자 입력)의 예창패 자료를 업로드해달라고 안내한다:

```
2026년(또는 선택한 연도) 예창패 자료를 업로드해 주세요.

📰 [선택] 2026년 모집공고 (HWP/PDF)
📄 [선택] 2026년 사업계획서 양식 (HWP/PDF)
📋 [선택] 2026년 주관기관 소개 자료 (HWP/PDF)
❓ [선택] 2026년 모집공고 주요 질의응답(Q&A) (HWP/PDF)

파일을 업로드하지 않으면 기존 내장 자료 유지합니다.
```

---

## Step 3: 업로드된 파일 파싱

업로드된 각 파일에 대해 텍스트를 추출한다 (new.md의 Step 3 파일 처리 방법 참조):

### HWP 파일 처리
```bash
libreoffice --headless --convert-to docx --outdir /tmp/ "[파일경로]" 2>&1
pip install python-docx --break-system-packages -q 2>/dev/null
python3 << 'EOF'
from docx import Document
doc = Document('/tmp/[변환된파일명].docx')
for para in doc.paragraphs:
    if para.text.strip():
        print(f"[{para.style.name}] {para.text}")
EOF
```

### PDF 파일 처리
```bash
pdftotext "[파일경로]" - 2>/dev/null
```

---

## Step 4: 새 자료와 기존 프로젝트 비교

업로드된 새 자료를 분석하여 기존 프로젝트와의 변경 사항을 파악한다.

다음을 확인하고 사용자에게 변경 사항을 제시한다:

```
## 📊 2026년 자료와의 변경 사항 비교

### 섹션 구조 변경
- [ ] 신규 섹션 추가: [섹션명들]
- [ ] 섹션 제목 변경: [변경 전] → [변경 후]
- [ ] 섹션 제거: [섹션명들]

### 평가 기준 변경
- [ ] 문제인식 비중: 30~40% → [새로운 비중]
- [ ] 실현가능성 비중: [변경사항]
- [ ] 성장전략 비중: [변경사항]
- [ ] 팀(기업)구성 비중: [변경사항]
- [ ] 탈락 기준: [변경사항 또는 동일]

### 주관기관 변경
- 새로운 주관기관 추가: [기관명들]
- 기관 폐지/통합: [기관명들]
- 특화분야 조정: [변경내용]

### 자금 규모 변경
- 1단계 지원금: 20백만원 → [새 금액]
- 2단계 지원금: 40백만원 → [새 금액]
- 비목 추가/변경: [항목들]

### 기타 주요 변경
- 제출 서류 추가/변경: [항목들]
- 지원 자격 변경: [변경사항]
- 선발규모: [변경사항]

**선택할 변경사항:**
- 모두 적용 (추천)
- 선택적 적용 (섹션만, 평가기준만 등)
- 취소
```

---

## Step 5: 사용자 선택 수렴

사용자에게 어떤 변경사항을 프로젝트에 반영할지 선택하게 한다:

```
다음 중 어떻게 진행하시겠습니까?

1. 모든 변경사항 자동 적용 (권장)
   → 섹션 구조, 평가기준, 주관기관 정보를 모두 최신으로 업데이트합니다.

2. 일부만 선택해서 적용
   → 섹션만, 평가기준만 등을 선택할 수 있습니다.

3. 취소
   → 기존 프로젝트를 유지합니다.
```

사용자 선택에 따라 Step 6으로 진행한다.

---

## Step 6: bp-project.json 업데이트

선택된 변경사항을 `bp-project.json`에 반영한다.

**업데이트할 필드:**

```json
{
  "year": "2026",
  "data_source": "uploaded-2026",
  "template_source": "[새 양식 파일명]",
  "host_guide_source": "[새 주관기관 자료 파일명]",
  "sections": [
    {
      "id": "1",
      "title": "[새로운 섹션 제목]",
      "content": "[기존 내용 유지 또는 재구성]",
      "status": "draft_requires_update",
      "char_limit": [새 글자 수 제한],
      "notes": "2026년 공고에 따라 수정 필요"
    }
  ],
  "metadata": {
    "budget_1st_stage": "20백만원 → [새 금액]",
    "budget_2nd_stage": "40백만원 → [새 금액]",
    "evaluation_criteria": "[변경된 평가기준]",
    "host_institutions_updated": true,
    "update_applied_at": "ISO 날짜"
  },
  "updated_at": "ISO 날짜"
}
```

## Step 7: 기존 섹션별 마이그레이션 및 주의사항

기존에 작성된 섹션들을 새 구조에 맞게 재구성한다.

각 섹션별로:

```
### [섹션명] 마이그레이션 결과

**상태:** [유지됨 / 재구성됨 / 신규작성필요]

**문제점:**
- [2026년 평가기준에 맞지 않는 부분]
- [글자 수 제한 초과 여부]
- [신규 요구사항 미충족 부분]

**권장 수정:**
1. [구체적 수정 방향]
2. [추가해야 할 내용]
3. [삭제할 내용]

**다음 단계:** `/write [섹션번호]` 로 해당 섹션을 수정해 주세요.
```

사용자에게 변경사항이 크거나 중요한 섹션부터 우선 수정할 것을 권장한다.

---

## Step 8: 주관기관 재추천

새 자료에 포함된 주관기관 데이터로 상위 3개 주관기관을 재추천한다.

```
## 🏢 2026년 추천 주관기관 (업데이트)

### 현재 선택: [기존 주관기관명]
- **상태:** [유지됨 / 통합됨 / 폐지됨]
- **추가 안내:** [변경사항]

### 새로운 추천
기존과 달라진 TOP 3:
1. [기관명]
2. [기관명]
3. [기관명]

**선택:** 기존 주관기관 유지 / 새로운 주관기관으로 변경
```

---

## Step 9: 최종 요약 및 완료

```
## ✅ 프로젝트 업데이트 완료

### 적용된 변경사항
- 연도: 2025 → 2026
- 섹션 구조: [변경사항 요약]
- 평가기준: [변경사항 요약]
- 자금 규모: 1단계/2단계 [변경사항]
- 주관기관: [변경사항]

### 작성 상태
- 유지된 섹션: [개수]
- 수정 필요 섹션: [목록]
- 신규 작성 섹션: [목록]

### 다음 단계
1. `/write [섹션번호]` 로 수정 필요 섹션부터 시작하세요.
2. `/review` 로 2026년 평가기준에 맞는지 검토하세요.
3. 모두 완성되면 `/export word` 또는 `/export pdf` 로 최종 출력하세요.

**참고:** 이전 연도 자료로 돌아가려면, 새로운 `/new` 프로젝트를 생성하거나
`bp-project.json`에서 `year` 값을 변경해 주세요.
```

---

## 사용 예시

```
/update 2026
→ 2026년 모집공고, 사업계획서 양식, 주관기관 자료, Q&A 파일 업로드 요청

/update
→ 연도를 입력해달라는 메시지 출력

/update 2026 [파일1] [파일2] [파일3]
→ 각 파일을 파싱하고 비교하여 변경사항 제시
```
