---
description: 외부 URL 자료를 분석하여 사업계획서 내용에 반영
allowed-tools: Read, Write, Bash, WebFetch, WebSearch
argument-hint: [URL 또는 검색 키워드]
---

외부 웹 자료(기사, 보고서, 통계, 경쟁사 정보 등)를 수집·분석하여 예창패 사업계획서의 특정 섹션에 반영할 수 있는 형태로 정리한다.

---

## Step 1: 프로젝트 파일 로드

워크스페이스에서 `bp-project.json`을 읽는다.
파일이 없으면: "먼저 `/new` 명령으로 예창패 프로젝트를 시작해 주세요."라고 안내하고 중단한다.

---

## Step 2: 자료 수집 모드 결정

$ARGUMENTS를 분석하여 모드를 결정한다:

### 모드 A: URL 직접 입력
- 사용자가 URL을 직접 제공한 경우
- 예: `/research https://www.example.com/market-report`
- 해당 URL의 콘텐츠를 WebFetch로 가져온다

### 모드 B: 키워드 검색
- 사용자가 URL이 아닌 키워드를 입력한 경우
- 예: `/research AI 헬스케어 시장 규모 2025`
- WebSearch로 관련 자료를 검색하고, 상위 3~5개 결과를 사용자에게 보여준 후 선택하게 한다

### 모드 C: 인터랙티브
- $ARGUMENTS가 없으면 사용자에게 질문한다:

```
어떤 자료를 찾아볼까요?

1. 🔗 URL 직접 입력 — 분석할 기사/보고서/사이트 URL을 알려주세요
2. 🔍 키워드 검색 — 찾고 싶은 내용을 설명해 주세요
3. 📊 시장/산업 데이터 — 아이템 관련 시장 규모, 성장률, 트렌드 자동 검색
4. 🏢 경쟁사 분석 — 경쟁사/유사 서비스 정보 수집

현재 아이템: {bp-project.json의 title}
```

---

## Step 3: 자료 수집 및 분석

### 3-1. URL 수집

**단일 URL인 경우:**
WebFetch로 해당 URL의 콘텐츠를 가져온다.

**키워드 검색인 경우:**
WebSearch로 검색한 뒤, 결과를 보여주고 사용자가 선택한 URL들을 WebFetch로 가져온다.

**시장/산업 데이터 자동 검색인 경우:**
bp-project.json의 title, 아이템 분야 키워드를 활용하여 아래 검색어들로 WebSearch를 수행한다:
- "{아이템 분야} 시장 규모 전망"
- "{아이템 분야} 산업 동향 {현재 연도}"
- "{아이템 분야} TAM SAM SOM"
- "{아이템 분야} 정부 정책 지원"

**경쟁사 분석인 경우:**
- "{아이템 분야} 스타트업 경쟁사"
- "{아이템 분야} 서비스 비교"
- "{아이템명} 대안 대체재"

### 3-2. 콘텐츠 분석

가져온 콘텐츠에서 다음을 추출한다:

1. **핵심 데이터/수치**: 시장 규모, 성장률, 사용자 수, 투자 금액 등
2. **트렌드/인사이트**: 업계 동향, 기술 변화, 정책 방향
3. **경쟁 정보**: 경쟁사 현황, 차별점, 시장 포지셔닝
4. **문제/고충점**: 기존 솔루션의 한계, 고객 페인포인트
5. **출처 정보**: URL, 발행일, 매체명 (사업계획서에 출처 표기용)

---

## Step 4: 섹션 매핑 및 활용 방안 제시

분석 결과를 예창패 사업계획서 섹션별로 매핑하여 보여준다:

```
📊 자료 분석 결과
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📰 출처: {매체명} ({발행일})
🔗 URL: {원본 URL}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 활용 가능 섹션:

┌─ 1. 문제 인식(Problem) ─────────────────────┐
│ • 시장 규모: {추출된 수치} (출처: {매체명})    │
│ • 문제점: {관련 내용 요약}                      │
│ → 기존 솔루션의 한계를 뒷받침하는 근거로 활용   │
└──────────────────────────────────────────────┘

┌─ 2. 실현 가능성(Solution) ──────────────────┐
│ • 기술 동향: {관련 내용}                       │
│ → MVP 개발 방향성 또는 기술 스택 근거로 활용    │
└──────────────────────────────────────────────┘

┌─ 3. 성장전략(Scale-up) ─────────────────────┐
│ • 시장 전망: {관련 수치}                       │
│ • 경쟁 현황: {경쟁사 정보}                     │
│ → TAM/SAM/SOM 산출 또는 경쟁 우위 논증에 활용   │
└──────────────────────────────────────────────┘
```

## Step 5: 반영 방법 선택

사용자에게 반영 방법을 제안한다:

```
이 자료를 어떻게 활용할까요?

1. 📝 특정 섹션에 바로 반영 — 선택한 섹션 내용에 자료를 녹여서 작성/수정
2. 📋 리서치 노트로 저장 — research-notes.md에 정리하여 나중에 활용
3. 🔄 추가 자료 검색 — 비슷한 주제로 더 검색
4. ✅ 확인 완료 — 분석 결과만 참고
```

### 옵션 1: 특정 섹션에 반영

사용자가 섹션을 선택하면:
1. 해당 섹션의 현재 내용을 확인한다 (bp-project.json의 sections에서)
2. 수집된 자료의 관련 데이터를 반영하여 섹션 내용을 보강/수정한다
3. **출처 표기**: 수치나 데이터를 인용할 경우 "(출처: {매체명}, {연도})" 형태로 표기한다
4. 변경 전/후를 보여주고 사용자 확인을 받는다
5. bp-project.json을 업데이트한다

### 옵션 2: 리서치 노트로 저장

워크스페이스에 `research-notes.md` 파일에 누적 저장한다:

```markdown
## {날짜} - {주제}

### 출처
- URL: {url}
- 매체: {매체명}
- 날짜: {발행일}

### 핵심 내용
- {추출 데이터 1}
- {추출 데이터 2}

### 활용 가능 섹션
- 문제 인식: {활용 방안}
- 성장전략: {활용 방안}

---
```

기존 research-notes.md가 있으면 하단에 추가한다.

## Step 6: 반복 또는 종료

작업 완료 후:
```
자료 반영이 완료되었습니다.

추가로 검색하거나 다른 URL을 분석하려면 `/research`를 다시 실행하세요.
사업계획서 섹션을 이어서 작성하려면 `/write`를 사용하세요.
```

## 가이드라인

### 사업계획서에 자료 반영 시 주의사항

1. **출처 명시**: 외부 데이터를 인용할 때는 반드시 출처를 함께 표기한다
   - 예: "국내 AI 헬스케어 시장은 2027년까지 X조원 규모로 성장 전망 (한국보건산업진흥원, 2024)"
2. **최신성 확인**: 2년 이상 된 데이터는 주의를 표시하고, 더 최신 자료 검색을 제안한다
3. **구체적 수치 활용**: 평가위원이 신뢰할 수 있는 구체적 수치와 공신력 있는 출처를 우선한다
   - 우선순위: 정부/공공기관 보고서 > 전문 리서치기관 > 언론 기사 > 블로그
4. **섹션별 연결**: 데이터는 단순 나열이 아닌 해당 섹션의 논리 흐름에 자연스럽게 녹여야 한다
   - 문제 인식: "이러한 시장 상황에서 기존 솔루션은 ~한 한계가 있다"
   - 실현 가능성: "이 기술 동향을 활용하여 ~를 개발할 수 있다"
   - 성장전략: "~시장의 성장에 발맞추어 ~전략으로 확장할 수 있다"
5. **분량 관리**: 전체 사업계획서 15페이지 제한을 고려하여 핵심 데이터만 선별 반영한다
6. **저작권 주의**: 외부 콘텐츠를 그대로 복사하지 않고, 핵심 수치/팩트만 인용하며 자체 서술로 작성한다

### 섹션별 자주 필요한 자료 유형

| 섹션 | 유용한 자료 유형 | 검색 키워드 예시 |
|------|----------------|----------------|
| 문제 인식 | 시장 규모, 문제 통계, 기존 솔루션 한계 | "XX 시장 규모", "XX 문제점 통계" |
| 실현 가능성 | 기술 동향, 유사 사례, 특허/논문 | "XX 기술 트렌드", "XX 개발 사례" |
| 성장전략 | 시장 전망, 경쟁사, TAM/SAM, 정책 | "XX 시장 전망 20XX", "XX 경쟁사 분석" |
| 팀 구성 | 산업 전문가 요건, 채용 트렌드 | "XX 스타트업 핵심 인력" |
